# 道の駅チェックイン（ネイティブ版・実験）

Web版「道の駅チェックイン」を、Expo（React Native）で作り直す実験プロジェクト。
完成版：駅リスト（全1,234駅）＋チェックイン＋統計カード（訪問駅数・訪問回数・完全制覇した都道府県・前回の訪問から）＋都道府県別の進み具合（バー表示）＋都道府県フィルター＋バックアップ（Web版と互換）＋ダークモード。デザインはWeb版に合わせて紫基調・カード型UI。

## 試し方（iPhone）

1. App Storeで「Expo Go」を入れる
2. Snackのページを開く：
   https://snack.expo.dev/nTvQy_r8_feEPDGB07zUP
3. ページの案内から Expo Go で開くと、自分のiPhoneで動く

## 使い方

- 駅をタップ → 今日の日付でチェックイン（もう一度タップで今日の分を取り消し）
- 記録は端末内（AsyncStorage）に保存。最小版の記録は自動で引き継がれる
- 検索は駅名・よみ・都道府県に対応、都道府県チップで絞り込みも可
- ⚙設定からバックアップの書き出し（共有）・読み込み（貼り付け）。Web版で書き出したバックアップも読み込める
- ダークモードは端末設定に追随、⚙設定で手動切替も可
